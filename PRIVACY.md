# Privacy Policy

**Last updated: 2026-08-22**

This repository ("the App") is a personal automation tool that generates
AI-created short-form video content and publishes it, via the official
TikTok Content Posting API and the official Instagram Graph API, to social
media accounts owned by the developer of this repository.

## What data the App handles

- **Platform access tokens**: Access tokens for TikTok and Instagram are
  stored as encrypted GitHub Actions secrets. They are never committed to
  the repository or exposed in logs, and are used exclusively to publish
  content to the developer's own connected accounts.
- **Generated content**: Video/image files and captions generated by the
  App are committed to this public repository so they can be fetched by
  the platform APIs during publishing. No personal data about third
  parties is included in this content.
- **No end-user data**: The App does not collect, process, or store any
  data belonging to TikTok or Instagram users other than the developer's
  own connected accounts. It does not have a login flow for third-party
  users and is not distributed to other users.

## Third-party services

The App calls the official TikTok Content Posting API, the official
Instagram Graph API (Meta), and a Hugging Face model inference API for
image generation. Each of these services processes data (e.g. generated
prompts, uploaded media) under their own respective privacy policies.

## Data retention

Generated content remains in this public GitHub repository's history.
Access tokens can be revoked and rotated at any time via each platform's
own account settings.

## Contact

Questions about this Privacy Policy can be raised via GitHub Issues on
this repository.
