# Musik fuer Reels (optional)

Lege hier lizenzfreie Musiktracks ab (`.mp3`, `.wav`, `.m4a` oder `.aac`).
`generate_reel.py` wählt automatisch einen zufälligen Track aus diesem Ordner und legt
ihn gedämpft unter das Reel. Ist der Ordner leer, wird das Reel einfach **stumm** erstellt
- kein Zutun nötig.

## Wo bekomme ich lizenzfreie Musik?

- [YouTube Audio Library](https://www.youtube.com/audiolibrary) - kostenlos, Download als MP3
- [Pixabay Music](https://pixabay.com/music/) - kostenlos, keine Attribution nötig
- [Uppbeat](https://uppbeat.io) - kostenlos mit Attribution oder bezahlter Lizenz ohne

Empfehlung: 3-5 ruhige, cinematic/ambient Tracks (passend zum Mindset/Motivation-Stil)
herunterladen und hier ablegen. Bitte bei jeder Quelle die Lizenzbedingungen prüfen,
bevor der Track kommerziell auf Instagram verwendet wird.
